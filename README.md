# 星烬纪元 / Emberfall

Unity 3D 即时战斗 RPG 单机原型，当前使用 **Unity 6（6000.6.3f1）、Windows 64 位、Built-in Render Pipeline**。参考动作 RPG 的技能连招、闪避、副本和装备成长玩法，角色、名称与场景均为原创程序化内容。

## 安装到其他电脑

已生成并验证的 Windows 64 位发行文件位于本地 `Builds/Release`（约 35 MiB）：

- `Emberfall-Setup.exe`：运行安装器，选择安装位置，可创建桌面快捷方式。默认安装到当前用户的程序目录，不需要管理员权限。
- `Emberfall-Windows-x64.zip`：免安装版。完整解压后运行 `Emberfall.exe`，不要只复制 exe。

程序与存档完全分离。安装或更新游戏不会包含、删除或覆盖玩家存档。没有迁移存档的新电脑可以直接创建新角色。存档迁移步骤见下方「存档与换电脑」。

本版本安装器不写卸载注册表项。卸载时删除专用游戏安装文件夹和桌面快捷方式即可，独立存档仍会保留。

## 开始试玩

1. 在 Unity Hub 安装 **Unity 6**，当前验证版本为 `6000.6.3f1`，并勾选 **Windows Build Support (Mono)**。开发机器上已检测到该编辑器与构建组件。
2. Unity Hub → Projects → Add → Add project from disk，选择克隆后的项目根目录（本机为 `E:\MyGame`）。不要创建新的 URP/HDRP 项目。
3. 等待首次导入和脚本编译完成。项目指南会自动打开，点击 **开始试玩**。也可以使用菜单 **Emberfall → 开始试玩 Play**。
4. 选择剑卫、元素师或游侠，然后点击「启程」。若有存档，可选择「继续冒险」。

`Assets/Scenes/Main.unity` 是启动场景；进入 Play 后会自动创建世界、角色、摄像机和界面，所以编辑状态的场景为空属于预期行为。无需下载模型、贴图、商业插件或付费素材。

若编辑器安装在默认位置，可运行 `Tools/Open-Unity.ps1`。自定义位置使用：

```powershell
.\Tools\Open-Unity.ps1 -UnityPath 'D:\Unity\Editor\Unity.exe'
```

## 已实现玩法

- **三种职业**：剑卫近战范围斩击，元素师远程法术与冰霜控制，游侠快速射击与群体箭雨。
- **即时战斗**：鼠标瞄准、连发普通攻击、闪避无敌、技能冷却、投射物、范围伤害、击退与眩晕。
- **原野探索**：风语原野、营地、遗迹传送门，史莱姆、哥布林与魔灵巡逻、追击和重生。
- **副本**：沉星遗迹三波挑战，最终 Boss 星蚀巨像有范围重击、冲锋与扇形弹幕；攻击有红色预警。波间回复生命，通关给予额外经验和金币，后续挑战阶数上升。
- **主动与被动**：每职业 10 个基础技能，其中 8 主动、2 被动。技能区分输出、控制、位移、增益、防御和治疗；被动学习后自动生效，不能放入主动快捷栏。
- **原技能进阶**：每升一级获得 1 技能点；基础技能按 2 / 4 / 6 / 8 / 10 / 13 / 16 / 20 / 25 / 30 级开放。学习和升阶各消耗 1 点。强化需基础解锁等级 +8，觉醒需 +18；继续使用同一个技能，不新增技能格。进阶改变数值、范围、段数、特效或控制/防护机制，技能界面可预览各阶段。
- **战斗取舍**：低阶主动技能低消耗、短冷却；高阶爆发消耗更高，终极技能基础冷却 90 秒。能量上限 100，每秒恢复 4，普通攻击真实命中额外恢复 8；技能伤害不回能。翻页、换键、重新配置技能都不会重置技能冷却。
- **快捷栏**：三页，每页十格，默认 Z/X/C/V/B、1/2/3/4/5。主动技能可任意分配和卸下，按键可以自定义；被占用的技能键自动交换，移动及功能键保留。
- **装备养成**：武器、护甲、饰品；普通、稀有、史诗、传说四种品质；装备有等级要求，可比较、替换、出售、强化至 +10；Boss 必掉稀有及以上品质装备。
- **补给与存档**：药水回复 50% 最大生命；背包商店购买；本地自动存档、备份恢复与存档校验；死亡损失 10% 金币，保留装备、经验和技能。
- **界面与音效**：中文职业选择、血量/经验/技能栏、小地图、背包、技能学习面板、暂停、死亡与通关提示，以及程序化生成的战斗音效。

## 构建 Windows 游戏

Unity 菜单 **Emberfall → 构建 Windows 游戏 Build**。输出为 `Builds/Windows/Emberfall.exe`，分发时需要整个 `Builds/Windows` 文件夹。

或关闭该项目的编辑器后，在 PowerShell 运行：

```powershell
.\Tools\Build-Windows.ps1
# 编辑器在自定义目录时：
.\Tools\Build-Windows.ps1 -UnityPath 'D:\Unity\Editor\Unity.exe'
```

日志位于 `Logs/windows-build.log`。编辑器工具会设置窗口尺寸、输入轴对应的传统输入、构建场景、线性色彩和运行时需要的着色器保留列表。

构建后运行 `Tools/Package-Release.ps1`，生成安装器和完整免安装 ZIP。安装器源码位于 `Tools/Installer/Installer.cs`，可使用 `--verify-payload` 只校验内嵌发行文件，不执行安装。

## 存档与换电脑

使用 `Application.persistentDataPath`，Windows 通常为：

```text
%USERPROFILE%\AppData\LocalLow\EmberfallStudio\Emberfall\emberfall-save.json
```

游戏暂停菜单提供存档位置入口；Unity 菜单 **Emberfall → 打开存档文件夹 Saves** 也可定位。每次角色状态变更及定时保存都会写入存档，使用临时文件与原子替换，并保留 `.bak`。存档包含职业、等级、经验、金币、背包装备、技能进阶、三页配置和自定义按键，不依赖原电脑用户名、安装路径或机器标识。

1. 旧电脑先保存并退出游戏，复制 `emberfall-save.json`；建议同时保留 `emberfall-save.json.bak`。
2. 新电脑安装/解压游戏并运行一次，从暂停菜单或上述路径找到其存档目录，然后退出游戏。
3. 将旧存档复制到新电脑的该目录。若新电脑已有角色，先另外备份再覆盖。
4. 再次启动，点击「继续冒险」。没有复制存档也可以点击「启程」初始化新的冒险。

当前只有一个角色槽位；创建新角色会要求确认覆盖。退出后再次进入会回到营地，不保存未完成副本的波次。升级版读取早期三技能存档时会保留角色与装备；不符合新进阶等级门槛的阶段会返还技能点，并明确提示。
