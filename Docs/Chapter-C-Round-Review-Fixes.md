# Independent review corrections

The first frozen C-round candidate passed its managed suite, but independent production-path review found gaps that the old assertions did not cover. These corrections are required before merging that candidate.

- A complete chapter means Star Platform completion. Forest and Redrock alone do not enable the shared first-core entitlement, including after reload. The completion transaction and profile normalization now use that same boundary. Production service tests cover both claim orders with the legacy mode, failed Star saves and repeats. The earlier test that expected a Forest reward was an incorrect requirement oracle and has been replaced.
- Real chapter death calls the failure snapshot path before canceling the experience ledger. The host harness now extracts and executes actual `OnPlayerDied`, then renders the real result presentation, preserving partial seals, last hit, concrete failure reason and earned kill XP. Calling a test-only failure helper was insufficient.
- Only chapter Hard/Hero counterplay uses deferred attack-batch arbitration. Normal and legacy bosses retain immediate exposure, so the interrupting hit still receives the original 1.35 multiplier. The regression executes actual `EnemyController.TrySkillInterrupt` and `TakeDamage`, not just the phase state.
- Desktop hotbar slots query typed opportunities by `LearnedSkillAtSlot` identity. The real drawing recorder covers remapped skills, inactive slot types and status precedence. Generic HUD text and mobile-only tests did not establish desktop integration.
- Compact collection controls must occupy space outside the rendered model viewport. Preview geometry and clock-boundary checks supplement lifecycle tests, which alone cannot establish unobscured composition or angular continuity.

Review still does not establish Unity rendering, device controls or GPU performance. Author aggregates, compiled negative controls and independent source review are separate evidence categories.
