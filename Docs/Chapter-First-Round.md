# 失联的星路：首轮章节

本轮用独立章节宿主连接三个可重玩的双房节点，不替换旧五种模式。首章入口来自三营地NPC；旧营地解锁规则、存档version 1和平台设置保持兼容。

| 节点 | 房间目标 | 空间与推进策略 |
|---|---|---|
| 林庭复明 | 双封印净化 → 撤离 | 中央障碍与外围环路；封印分置两侧，需要换位清理争夺者 |
| 赤岩断供 | 猎杀供给者 → 撤离 | 双叉通道；困难及英雄双远程异侧交叉火力、双守卫驻出口，优先断供再处理守门 |
| 星台封印 | 休整 → 阶段首领和护卫 | 三辐射通路与开放中心；休整恢复后处理中断锚点和顺序预警 |

同节点普通通关解锁困难，困难通关解锁英雄。生命/伤害系数分别为1/1、1.20/1.15、1.35/1.25，在既有阶数成长后仅应用一次。困难林庭增加援护；英雄林庭和赤岩分别加入有界荆棘脉冲、热浪线。星台困难每阶段最多追加一道完整2.2秒顺序预警；锚点被破坏、中断或无锚点会取消追加。英雄星台改变种子方向与锚点候选，不并行叠加光束。上述数值是待试玩校准的初值。

普通房最多六敌，首领房首领加两护卫，无无限增援。出生点复用导航安全校验，保证入口距离、彼此间距和可达性。星图地标按已持久保存的章节完成记录逐段修复。

奖励基础碎片为1/1/2，套用既有阶数奖励带，各节点首次额外1枚，难度不增加倍率。UI展示本次入场收据的实际奖励。完成、奖励、首次标记和收据在同一候选存档内原子提交；保存失败可用同收据重试，成功前不解锁或修复地标。仅完整星台节点推进共享最高阶数。章节不会触发旧模式首通核心，旧存档最高阶数也不推导剧情完成。

## 验证边界

新增检查覆盖存档迁移、顺序/难度/阶数入口、原子失败与重试、重复回调、旧首通资格、真实宿主流程、移动返回/固定操作区、六房空间导航与危险区绕行、同种子重现、困难赤岩实际双远程编队，以及首领追加预警取消。默认聚合包含既有模式回归与必须编译成功且命中特定断言的负对照。

托管检查替代了Unity场景和部分引擎对象；几何统计不能证明战斗体验。当前环境没有Unity Editor，未运行真实渲染、AI试玩、触控、iPad设备、平台构建、截图或录像。缓存2021参考程序集编译仅作补充，不是项目6000.6版本验证。三平台最终聚合结果另随冻结记录报告。
