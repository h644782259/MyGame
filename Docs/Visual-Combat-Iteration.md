## 实施顺序

1. 接触帧、危险与打断标识、材质/图标/技能配方、移动反馈、飘字和菜单可达性；补首领追击预算、占点体型交叠和可运行战斗记录场景。
2. 免费伙伴指令与短时增益分离；职业教学以实际命中/有效刷新为准；房间祝福和存档进度使用现有流程；逐步更新角色、伙伴与首领动作。
3. 职业轮廓、翅膀与营地识别；配装/收藏展示；前景遮挡与可配置移动控件。

## 已集成的第一批

- 即时普攻从接触/放箭姿势开始恢复，与实际攻击间隔共用时间线；取消和场景切换清理姿势。
- 装甲、武器、服装、皮肤、木材和叶冠显式材质；唤灵图标对应实际技能；区域技能选择显式视觉配方。
- 危险边界固定橙红；可打断信息使用独立青色符号与倒计时，不用安全色替换危险范围。
- 遮挡裁剪复用伤害/预览范围规则；大型形体贴墙时保守隐藏，须画面检查稀疏程度。
- 装饰预算涵盖粒子/闪电/死亡碎光，禁用时释放；机制提示使用独立飘字容量。
- 手机生命数值、治疗存量/限制、闪避/技能状态和附近失败信息；目标/锁点标识；按字体尺寸和放大上界进行飘字放置。
- 五个模式入口完整布局、日志避让工坊、手机工坊保持滚动、桌面长技能文本测量滚动。
- 免费伙伴集火/召回只改变导航与目标；显式目标不随契约增益计时到期，死亡/超距/战斗世代清理。

## 验证边界

纯状态/几何/源码契约及编译用于发现逻辑和接线问题，不能等同于实际战斗、画面可读性或新手体验。新增检查登记在 `Tools/cloud-validation.py`，旧副本检查继续保留。每个最终报告需关联固定提交与源码哈希，修改期间的报告不作为最终验收。

当前 Debian 环境未运行 Unity Editor/Player，也未进行真机、截图或视频验收。官方 Unity 6000.6.3f1 下载在代理 CONNECT 阶段返回 403，未绕过代理、许可或安全策略。此环境参考 API 编译使用仓库固定的 Unity 2021.3.33 引用；父任务在独立环境执行的 Unity 6.3 引用编译须按各自提交报告，不能混为运行验收。

最终人工复核应覆盖：568×320 十技能与近战可见区、1.8 倍字体/高 DPI、降特效危险边界、墙边远程与大冰火形体、连续快速普攻/蓄力/闪避、伙伴六秒显式目标、首领追击与柱绕行、死亡/暂停/房间切换，以及 iPad 字体与触控。
