# 本轮设计与验收边界

本轮基线：Windows `3b224e36f58d300b102a01b287c8077cc5ff1261`、iOS `a0acdf3233ef45bfef2f9871242ca94ea749f777`、Android 源码 `a36c66550abd9d8cac3b7ad31bb0977a23d82d99`。继续复用三营地、三试炼、五房远征、阶段首领和现有配装系统；不另造同名系统。

## 重复感与误导来源

- 战术圈画面和玩家判定为2.4米，敌人争夺原来另用3.8米中心距离；护援提示仅看供能者存活，实际伤害还受6米与视线限制。玩家难以判断引怪是否成功。
- 房间祝福固定三类池让部分公开祝福无法进入正常首选；休憩选择的强化关系也不唯一。
- 所有撤离房敌人使用通用追击，守门、追击、援护和侧线缺乏空间分工。
- 晶核原来必须等开门才可触发，奖励直接改内存再保存；这同时削弱取舍和失败重试可靠性。
- 免费伙伴集火与付费临时命令互相覆盖；视觉姿态又参与普攻恢复判定，表现调整会影响玩法。
- 路线把可选机制装备当成基础门槛，成长目标没有具体机制/物品身份；入口也缺乏奖励与目标适配的明示。

## 复现与限制

默认验证：`bash Tests/Run-CloudValidation.sh --dotnet <dotnet8>`。源码检查：逐个运行 `Tests/*SourceTests.py`。成长探针：`Tools/sample-growth-review.py --dotnet <dotnet8> --output <新目录> --compare Docs/Growth-Review-Rule-Probes.csv`；奖励方案对照：`Tools/sample-reward-comparison.py --dotnet <dotnet8> --output <新CSV>`，明确只比较保证材料，不估算耗时或胜率。

Windows/Android项目为6000.6.3f1，iOS保留6000.6.4f1及原字体/iPad配置。精确API验收需各平台固定提交分别运行 `--unity-editor <匹配Editor>`；平台Editor变体包括平台宏及可用扩展程序集。当前工作环境没有Unity Editor或Unity6程序集。旧2021引用的补充静态编译只帮助发现语法/整合问题，不是Unity6验收。

托管替身、种子分布、几何与规则探针均不是Unity试玩。真实移动操作、引怪4秒占领的手感、画面层次、材质/字体、GPU特效、原生RT/材质生命周期、音画时点及原生平台构建仍待引擎/设备验收。不要据此宣称性能、平衡或可玩性已经验证。32条支线收据是有界重放保护；更久的陈旧世界回调由会话/房间身份隔离，不宣称任意历史GUID防伪。
