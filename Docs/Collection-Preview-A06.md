# Collection preview composition and rendering

The preview retains one isolated `CombatModel.Hero` mannequin and the existing immutable appearance snapshot. It never equips the actual player or changes a save. UI owners select `CollectionPreviewComposition.Full`, `Weapon`, or `Back` through `SetComposition`; switching mode establishes a front/weapon 20° or back 160° default, while repeated calls preserve manual rotation. `SetViewport(pixelWidth,pixelHeight,mobile)` expects the final on-screen pixel size after the caller's GUI transform, not unscaled logical layout units. The original `Render` signature remains valid.

Full mode fits active visible renderer bounds. Weapon mode frames actual weapon-rig/equipment/fashion renderer subtrees; Back frames fashion wings plus upper-body context. Missing specialty geometry has a bounded upper-body fallback. Camera fitting accounts for aspect and the 8° downward view. The mannequin's current uniform Y breathing is excluded from fitting so it cannot pump the camera zoom. No model, costume or world geometry is replaced.

Native surface requests are quantized in 16px buckets, minimum 64px per dimension, with a maximum side of 512px on mobile or 768px otherwise. MSAA requests 2×/4× and uses the supported sample count, bounded by that request; hardware can fall back to 1×. A material resize detaches/releases the old surface before allocating the replacement, at most once per frame. Layout/input GUI passes never construct or render the stage. A lost native surface invalidates pixels without requiring a new mannequin.

Three fixed, shadowless key/fill/rim lights and fixed ambient color illuminate the existing model materials. During the synchronous offscreen render, cached non-preview lights are temporarily excluded from the preview layer, and world fog is disabled; a `finally` restores all original masks and ambient/fog settings. `Invalidate()` refreshes this light cache on resume. A single 64×64 radial-alpha quad provides a soft contact cue, not a claim of physically simulated soft shadows. A bounded arc rotates 12°/second; a rooted Y-scale breath stays within ±0.4%. Presentation advances once per frame on unscaled time, caps resume spikes at 100ms and requests about 20 renders/second. There is no attack, navigation or gameplay animation driver in the mannequin.

Dispose disables/destroys the isolated stage and mannequin, detaches/releases the RT, and destroys both preview-owned materials and the alpha texture. Model-owned palette cleanup stays with CombatModel. Existing UI panel/death/background/owner lifecycle hooks continue to call Dispose; UI integration is a separate owner change.

Validation: 14,981 pure surface/composition/motion assertions, existing plus added source wiring contracts, and a narrow compile against cached Unity 2021 API references with a CombatModel contract stub (zero warnings/errors). This is not full-project compilation, Unity 6 API acceptance, native resource/driver validation, rendered framing/lighting review, or touch/device testing. Full/weapon/back screenshots, large wing/staff clipping, unsupported-MSAA recovery and repeated open/close/native-memory behavior remain engine acceptance tasks.
