# 0.4.0 · 画面、触屏、存档与远征扩展

这是 Windows/iPhone/iPad 源码更新。旧 0.3.1 安装包不包含本轮修改；新安装包、Xcode/IPA、真实画面与设备体验仍需在可运行的 Unity 环境构建验收。

## 画面与动作

- 共享倒角模型、圆润岩石、独立金属/布料/晶体材质；柔性披风、关节化敌人与四足伙伴动作，冷暖补光与平滑宝箱姿态
- 厚实的三维月牙斩、延迟生长的冰晶、扩张扭转的火焰和张开的召唤壳瓣；前摇、真实命中和消散分阶段演化，不再以线条叠加作为主要技能视觉
- 特效/飘字有并发上限与分层，降低地面填充和重复遮挡；危险预警保留独立边界。桌面4×、移动2× MSAA，没有像素化滤镜
- 原创星核图标使用一份1024×1024不透明RGB主图，配置Windows及iPhone/iPad/App Store尺寸槽位

详见 [程序化画面](Procedural-Visual-Upgrade.md)、[三维技能效果](Filled-3D-Skill-Effects.md)。几何与源码检查不等于观看过引擎画面。

## 手机与平板

- 安全区布局，战斗十个技能位置同时显示、两排各五格，没有翻页；被动与未学习技能显示不同状态且不可施放
- 移动端点击范围技能自动选择当前有效焦点/附近有效目标并释放，保留原有蓄力过程，无需二次选点确认；无有效目标时使用安全朝向落点
- 左摇杆、普攻、闪避、跳跃、药剂与技能分配独立触点；54单位技能格、48～84单位主要按钮，适配紧凑横屏与iPad
- 空白战斗区域上下拖动调整俯仰，带移动阈值和角度限制；UI、摇杆及技能触点不操纵镜头
- 所有滚动内容支持手指拖动，超过阈值后取消列表内按钮点击；桌面滚轮保留
- 接近传送门、下一房间出口和城镇NPC时显示独立交互按钮，无需准确点中小模型；支持摇杆与交互按钮同时触摸
- 暂停菜单居中，标题/存档/确认对话框使用大触控布局；行囊、技能、工坊、时装、宝箱与祝福改为专用安全区面板，固定48单位操作区、测量换行与内容滑动。紧凑手机分列表/装备详情，宽屏平板并列比较。长存档路径按实际字体完整折行，复制保留原文；宝箱写入失败也可打开菜单处理存档。实际字体和真机触达仍需验收

## 存档、退出与提醒

- 自动保存写回当前加载的稳定槽位；新角色只创建一次新槽。定时保存、正常退出和移动端后台事件使用相同身份，快速生命周期回调合并
- 暂停页仅保留一个手动「保存」入口，已有角色先确认覆盖；取消只取消本次手动写入，不关闭自动保存。暂停页也可读取存档，提供保存后读取、放弃未保存进度或取消
- 删除确认显示角色与完整稳定编号；取消不写入。删除覆盖主文件、备份与临时文件，中断标记阻止旧备份复活；测试只使用隔离假存档
- Windows标题/暂停页可退出游戏，保存失败则停留；iOS保存并返回主菜单，不强制终止应用。死亡/挑战结算也能打开菜单处理存档问题
- 手动学习、锁定、专精、快捷键、外观和药剂消耗也先原子写入，再更新当前角色；写入失败不扣点、不丢药剂、不报告虚假成功
- 红点提示可领取奖励、可学习技能，以及符合等级的同部位更高有效属性评分装备；机制取舍仍需自行比较。等级不足装备变暗、标注等级锁且服务层禁止装备
- 战斗复盘分为结果、真实记录的关键数值、奖励/进度、原因和简短建议卡片，不展示未记录的DPS或虚构统计

容量策略：最多新建64份角色、单次写入4MiB、一份轮换备份；已有额外角色/收藏/可恢复存档不自动清理。云检查与iOS导出日志使用固定latest位置，旧构建和历史报告保留。触屏面板详见 [行囊与奖励](Mobile-Inventory-and-Rewards.md)、[技能与工坊](Mobile-Skills-Workshop.md)。

见 [存档安全](Save-Safety-Storage.md)、[暂停存读档](Pause-Save-Load.md)。强杀、断电仍可能丢失最近一次成功保存之后的进度。

## 场景与玩法

- 三个城镇：风语营地、赤岩驿站、星望城；地图选择已解锁目的地，商人、铁匠与材料兑换NPC使用实际经济服务；交易失败回滚，锁定装备受保护
- 三个短试炼：守望林庭占点防守、烬河突围限时推进、蚀星斗场三轮首领；各自有地形、目标、敌人节奏与奖励。计时跟随战斗暂停，不在菜单、祝福选择或后台偷跑
- 大型五房远征：三个战斗房间、一次休憩/祝福选择、最终首领；清房后门解锁，顺序载入单个房间，含可选晶体支线。普通三波遗迹仍可进入
- 大型首领使用原创四足星环核心外形，70%/35%生命触发能量锚与旋转地面光束；打碎锚点或打断前摇打开核心暴露窗口。无需强制手动选小目标，范围技能可击中锚点
- 箱、罐和部分碎石可被普攻、投射物与范围技能击碎，障碍立即移除；少量生命/能量恢复，不发永久货币、不计入清怪数。每场景数量与碎片寿命有上限
- 14种局内祝福包含暴击、攻击、冷却、攻速及防护，各有明确数值/上限；指定技能可真正打断首领前摇，击退按普通/精英/首领抗性处理
- 实际进入新副本/新挑战时清空所有技能冷却并取消旧施法；波次与房间转换不重置冷却

详见 [试炼规则](Expedition-Mode-Rules.md)、[城镇与交易](Hub-Travel-Economy.md)、[大型首领](Large-Expedition-Boss.md)、[可破坏物](Destructible-Props.md)、[祝福和控制](Run-Blessings-Control.md)、[结构化复盘](Structured-Run-Recap.md)。调参属于设计值，尚无实测通关时间或性能保证。

## 验证边界

自动检查覆盖生产逻辑、存档失败/重入/稳定身份、触控几何/手势、奖励事务、房间状态、首领阶段、原有战斗成长回归、程序化网格及精确Unity API编译。最终检查数量和稳定源文件摘要以各仓库 `Tests/TestResults/Cloud-Latest/report.json` 本地报告为准；该目录不提交。

未执行：Unity编辑器/Play Mode、真实JsonUtility、着色器导入/GPU渲染/帧率、实际触屏、Windows打包安装、Xcode导出或IPA签名。环境本地套接字权限阻止Unity启动；iOS工程要求6000.6.4f1，当前兼容编译使用6000.6.3f1程序集。

验收优先级：四职业动作与新立体特效；敌方预警遮挡/碰撞一致性；手机十格技能和三指操作；内容滑动不误点；三城镇交易；短试炼与五房远征全流程、首领锚点打断；暂停/后台计时；存档删除、覆盖取消、读取失败和退出保存失败；平台图标实际显示。
