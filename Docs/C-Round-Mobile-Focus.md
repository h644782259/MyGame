# 移动固定目标 B 首批

世界轻触敌人固定后续普攻和适用技能；空白轻触解除。固定引用不写存档、不调用伙伴集火或召回。有效范围沿用原 `ResolveMobileAim` 和蓄力目标验证的 14 米，未新增另一套战斗距离。死亡、不在当前敌人列表、超出范围、玩家/战斗 epoch 变化清除，之后恢复原自动选择。被遮挡或超出当前技能距离时保留意图并拒绝该次新动作，不消费该动作；自范围技能及普通召唤契约保留各自语义。

普通契约存在显式团队目标时，准备入口与蓄力入口都读同一团队目标；固定敌人不变成主动伙伴命令。已开始蓄力仍执行捕获的点、敌人和方向，新点选只影响下一动作。固定目标方框、团队菱形、闭合蓄力落点和自动开口括角复用既有三个标记，不为每次点选生成对象。

世界候选与相机共用一个指针 owner；任意二维位移跨过原 9 逻辑单位阈值后永久成为拖动，仅纵向增量调俯仰。左摇杆可并行；第三指、动作或 UI 指针取消候选。开始/释放都必须处于允许的世界区域且命中同一敌人引用，重叠按屏幕距离、深度和稳定列表次序裁决。取消、触点丢失、UI/暂停门禁、视口重置或换房旧 epoch 不能提交。

`Tests/MobilePinnedTargetProductionTests.py` 使用真实 `ProcessPointer/Update/ResetInput`、投影选择、移动/技能瞄准、普攻、`Targeting.Begin`、目标确认、蓄力 Begin/Advance/Execute 方法；引擎值、场景及实际伤害结算端点使用托管替身。36 项覆盖上述所有权和目标链，默认三个负对照必须先编译成功并命中特定断言：旧 y-only 手势、旧最近敌人覆盖、旧遮挡技能回退。旧碎冰机会 28 项及两个负对照、多指生命周期 26 项继续通过。无需修改聚合工具即可单独以 dotnet 路径运行。

当前没有 Unity 6000.6 精确程序集或 Editor，未声称 Unity API 编译、触控投递、视觉可读性、帧时间或设备验收。仍须真机检查密集敌人点选、实际屏幕遮挡、握持移动与相机阈值。后续 C03 将把机会反馈进一步接到真实动作类型与兑现事件；此提交不改效果优先级或蓄力姿态 API。
