The initial package counted RegisterSkillHit callbacks, some of which precede actual damage. This follow-up leaves mastery core timing intact and instead credits practice cast hits at the EnemyController actual health-loss point. Optional cast attribution travels with player-owned direct and field damage; ordinary attacks, companion autonomous damage, DOT/reactions have no extra cast credit. All actual damage still accumulates once. No existing damage/critical/knockback values change.

Record-level tests cover zero/immune loss, clipped killing loss, repeated hit ticks, DOT/companion loss without duplicate cast credit; these are observed-event assertions, not Unity collision execution. Production wiring audit and Windows API build are included. Integrated runner fixtures with EnemyController doubles need the trailing optional `int practiceCastId=0` parameter. New projectile implementations should forward their successful paid cast ID to TakeDamage; never pre-credit from RegisterSkillHit.
