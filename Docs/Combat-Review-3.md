# 第三轮战斗、成长与可靠性检查

此轮是在0.4.0画面/触屏/远征快照之后单独进行的数值与逻辑检查。下面的伤害单位A表示角色当前非暴击攻击力；不包含敌方减伤、随机暴击、实机命中率或实测击杀时间。

## 从实际事件核对技能预算

旧源码中，觉醒剑刃风暴完整命中为16.88A、奥术风暴17.6A；九支扇形箭连同各自爆裂可在同一目标上叠到22.32A。它们与原终极技能完整序列约11.10/11.48A的关系不合理。修正没有统一放大终极技能，而是移除全局进阶倍率，把每个技能的主要段数、倍率、尾段、启动时间和持续领域预算放入生产规则。

- 剑刃风暴、奥术风暴、箭雨的觉醒完整非暴击预算为6.4 /6.8 /7.2A，包含收尾；各阶单独分配每次脉冲，不因持续时间和升阶同时放大而漏算
- 扇形箭共享一次施法的目标账本，后续同目标命中按100% /50% /25% /10%递减；箭矢和爆裂合计上限为3.2 /4.8 /6.4A。不同敌人独立计算，先前毒层的合法连招引爆单独计入
- 冰霜新星冰片对同一目标的额外伤害上限1.8A；相邻的低阶回响/陨星尾段也有显式预算，避免隐含多次相乘
- 终极技能保留既定整段上限，普通攻击、蓄力、进阶事件和召唤物的时间/伤害常量由实际运行代码和测试模型共享
- 完整时序发现召唤荆棘原有15.136A含残留毒伤、消耗28能量；修正为8.256A全生命周期，前5秒4.992A。引力印记从9.44降至7.04A。树灵本身未改伤害/寿命，其70能量的完整生命周期仍为21.112A，模型含1.10秒蓄力

细节、48条合法技能组合、5秒/10秒窗口、真实资源支出与未完成事件见 [组合预算](Combo-Budget.md) 和 [CSV](Combo-Budget.csv)。测试使用真实SkillRuntime消耗/回能/冷却，并核对召唤寿命、毒层引爆和碎冰。CSV是明示理想命中条件下的事件账本，不是所有流派排名，也没有把Boss生命除以一个假定DPS冒充实测。

## 目标与遮挡

实体墙、岩石及未破坏障碍阻挡直接攻击、地面放置、范围扩散和每一跳连锁。物理近战另要求地面路线可通行；魔法可跨水面。目标预览与释放共用放置裁剪，范围/锥形预览按相同遮挡规则截断；无变化的预览缓存到目标、角色朝向或地形版本改变为止。

护盾霜印、额外地面冲击和局部投射物出生段也检查遮挡，避免主攻击被墙挡住而附加段出现在墙后。投射物命中可破坏物时仍能击碎它，障碍移除后立即更新路线。独立场景中的远端技能投射物不会被错误当作角色枪口攻击拒绝。

## 时间与契约

- 首领弹幕后接近目标的行为有1.8秒/进度约束，无法有效靠近时回到可用的远程行为，避免卡在8.5米门槛
- 中毒、灼烧、范围持续伤害与引力印记使用有限调度；每帧最多补8次，先结清已到期事件再终止对象。正常/200ms/500ms及严重卡顿、刷新/消费/暂停分别测试，特效不随每个补偿tick重复爆量生成
- 蓄力契约保留起始目标和位置，释放时检查目标是否仍属于当前战斗；失效时使用原有效位置，不偷偷转锁后来鼠标指向的敌人
- 满编群契重施刷新现有伙伴最低剩余寿命，不叠加寿命、不回满血；完美闪避不再强制召回/清空目标，而给予伙伴3秒保护和一次16秒契约机会，覆盖实际14秒基础狼契约冷却并留操作余量

参见 [时序与契约](Combat-Timing-and-Contracts.md)。

## 成长和奖励安全

营地可退还已学技能2/3阶投入、保留1阶及前置；原精通重置独立保留。核心10点启用、20点增强，分别由技能→普攻、濒危受伤、完美闪避、实际技能能量支出触发；持续技能的所有附加段共享原施法编号，不能跨内部冷却反复触发同一次技能。

普通遗迹和全部试炼/五房远征使用同一有界阶数分档。装备稀有度、材料和宝箱金币按实际挑战阶数变化。已知本职业史诗机制装备可在第5阶里程碑后花24碎片升华，保留身份、等级、变体和永久部位强化，无随机重抽。

普通遗迹通关改为一次原子事务保存通关进度、金币、经验、材料和宝箱资格。写入失败时保留当前未结算编号；保存、返回营地或退出会先重试，放弃当前进度并读取别的角色才明确清除。所有终局，包括普通遗迹，拒绝迟到伤害/重复击杀回调，但保留普通通关后的移动和战利品整理。

副本、增援、晶核支线和房间敌人统一使用进入本局时的等级快照；阶数只在敌方强度公式中应用一次。升级不会在下一房间突然再抬高敌人等级。

详见 [进阶、阶数与升华](Progression-Growth.md)。

## 验证范围

独立生产逻辑测试、共享地形几何测试、时序尖峰测试、原有成长/存档回归、源代码接线检查和精确Unity API编译分别执行。编辑器验证脚本只在能运行Unity的环境才可执行；准备或编译脚本不代表引擎验证通过。

尚需真实Unity/目标设备检查：着色器导入与画面、实机多指交互、实际帧率、模型/范围遮挡观感、敌人/伙伴移动时的伤害与节奏、打包及安装。当前环境的Unity启动限制没有通过安全绕行规避。
