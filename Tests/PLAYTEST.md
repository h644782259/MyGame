# Unity 实机验收

面向 Unity 6（6000.6.3f1）与 Windows 独立游戏的手动验收清单。自动化检查以 `Tests/TestResults` 报告为准；列表本身不代表全部人工通过。

1. **导入与启动**：Unity Hub 导入项目，Console 无红色错误；指南打开；点击开始试玩；Game 窗口可看到职业菜单。分别检查 1280×720、1600×900 和更宽的窗口，文字、按钮及提示没有遮挡。
2. **三个职业**：分别创建角色；旧存档应要求覆盖确认；能移动、鼠标瞄准、持续普攻、滚轮缩放，剑卫/元素师/游侠的武器与攻击明显不同。走到地图各个方向不能离开圆形地面。
3. **战斗**：原野怪物追击、攻击预警和伤害正确；空格可以移动并在短时间内免伤；药水生命已满时不消耗；无药水时提示补给；打开 I/K 或 Esc 暂停时敌人不继续攻击。
4. **技能学习与进阶**：每职业恰有 8 主动、2 被动；从 2 至 30 级逐个开放。强化/觉醒分别需基础等级+8/+18；消耗技能点，原技能 ID 与快捷栏位置保持。检查数值、范围、特效、追加机制与预览一致；治疗不造成伤害，防御/增益不是纯输出，被动自动触发而不能主动施放。
5. **装备**：怪物掉落可在 I 查看；未满足等级的物品不能装备；装备改变属性；强化扣金币并提高数值；金币不足、+10 上限有说明；已装备物品不能出售。反复交换高/低生命护甲不能回血。
6. **副本**：2 级后从北方传送门按 T 进入；依次出现三波，波间回复生命；最终 Boss 有重击、冲锋、扇形弹幕；通关金币/经验和装备正确；T 返回后可再次挑战更高阶。
7. **状态边界**：施放持续技能后跨区或退回标题，旧技能不能伤害新场景；在波间离开副本，不应出现延迟生成的敌人；死亡后一次性扣 10% 金币，能复活回营地，装备和技能保留。
8. **存档**：关闭游戏重新启动，继续冒险恢复职业、等级、金币、技能、背包装备；进度回到营地。测试备份前先复制自己的存档到安全位置，再故意损坏主存档，继续游戏应恢复备份并明确提示。
9. **音效与窗口**：攻击、技能、拾取、升级、胜利和死亡有提示音；暂停菜单静音可切换；切到其他窗口后应自动暂停。
10. **Windows 构建**：使用 Emberfall 菜单构建，检查 Console 和 Build 日志；运行 `Builds/Windows/Emberfall.exe`；场景材质不发紫、字体正常、输入/菜单/保存均可用，再完整通关一次。
11. **快捷栏与资源**：检查默认 ZXCVB/12345 两排、三页切换、自定义按键、冲突键交换与保留键拒绝。相同技能换页/换键/重新配置后冷却继续；能量不足不能施放，普攻命中回能，空挥不回能；被动不占主动格。
12. **换电脑与安装**：在第二个 Windows 用户/电脑安装发行包；没有存档能初始化。退出后复制旧 JSON 到新存档目录，继续游戏应恢复角色、装备、进阶、页面和快捷键；程序安装目录改变不影响存档读取。
