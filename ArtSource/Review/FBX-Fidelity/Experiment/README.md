## Hardened measured domain

4923 source-vs-Blender-FBX-reimport samples: all five clips on a 1/16 source-frame grid plus .137 and .731 off-grid samples in each integer interval; Basic also includes all 1/32-frame points (midpoints of the proposed 0.0625 bake intervals); the original 288 actual production-policy forward/stop-restart layered inputs are included. This contains all original 4523 exploration points and all 240 integer clip frames. It is a dense finite sample test, not a mathematical supremum over continuous time.

Strict threshold is unchanged: deformed vertices and all six socket positions must each be < 0.0001 m. Deformed-vertex error is symmetric nearest-vertex distance within each of six matching meshes, accommodating FBX vertex reorder. Coordinates use float32 matrix transforms; prior legacy mathutils reports remain separate. All captured mesh/socket coordinates are checked finite before error reduction. Actual NaN mesh, Infinity mesh, and NaN socket negative controls reject, recorded explicitly in hardened-report.json.

## Helper and equivalence checks

The final helper locks Blender4.3.2 and the actual io_scene_fbx function signature. It requires the exact Vanguard rig/six-mesh/six-anchor selection, refuses unknown actions and non-FBX paths, checks FINISHED, uses only in-process settings._replace, and restores the original exporter function in finally. No installation file or source blend is written. Actual wrong-suffix, wrong-selection, and unknown-action controls reject; function restoration is asserted.

hardened-mixed.fbx was emitted using the helper and passed the dense run. After final suffix/FINISHED guard additions, helper-output.fbx was emitted by the exact final helper. helper-equivalence.json proves all five reimported animation curves are exactly equal to dense-tested hardened-mixed, including channel paths, indices, key coordinates, interpolation, handles, extrapolation and frame ranges. hardened-static-invariants.json separately proves its static data equal to original baseline: vertices/topology/UV/weights; vertex/corner/face normals and face material indices; bind bone matrices/parents; socket parent-local/default transform/display properties; full material node input defaults, shader scalar/color defaults, links, linked texture bytes/colorspaces and sampling properties.

Source hashes before/after remain unchanged. Historical report.json, mixed-report.json and their logs retain the initial failures/exploration. hardened-report.json retains baseline FAIL and candidate PASS separately. Raw FBX counts are parsed directly from AnimationCurve/KeyTime arrays, not inferred from Blender reimport key counts.

## Remaining boundary

**This validates Blender source→FBX→Blender roundtrip only.** The existing Unity importer does not explicitly set resampleCurves/animationCompression; this investigation changes neither. Unity native clip interpolation/compression can alter fidelity and requires independent acceptance in Unity. No Unity, device, GPU, native preview or whole-feature visual-quality claim is made.
